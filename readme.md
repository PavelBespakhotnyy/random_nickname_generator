# A simple random nickname generator written in C

 An adjective and a noun is taken from two txt files and combined into a random nickname

Example of use:
```
cc main.c
```

```
./a.out [number of nicknames you want to generate]

./a.out 5
```

Example Output:
```
MiserableChance
FarSlide
ScornfulAffect
WeightyExam
EcstaticHook
```
